Getting into Coding Again is Great!

I've been going mad for coding lately. I don't know what it is, maybe it's that I've had more energy. But I've been going nuts for Hugo. It's just wonderful for building fast, robust websites. I'm loving the automagical ways to organise content. Just, you make a folder and it just knows what layout to use? Lovely. Still haven't figured out favicons yet, but we'll get there.

I'm still limited on the amount of time I can spend on it due to illness but it's nice that I can work at my pace when working on projects. I'm hoping I can start studying in November, but alas, my health has to come first. I'm returning to my studies in web development and information design. We have a project in react and I'm hoping I can convince my teachers to allow me to develop in Vue instead as I had a lot of fun developing in that in the spring. React and Vue are fairly similar so I don't think it should be a problem. Vue just worked better with the way I think.

I started programming my personal site in Vue, but it felt like using a power drill to put up a nail, just overkill, so I moved over to Hugo. I wanted something lightning fast to load. And I'm glad I did. Although it was a lot of starting over. Especially as I had also switched operating systems on my computer during that time and lost some files as well. I'm now running Asahi Linux on my MacBook Air and it's struggling with everything I'm running on it, so there will need to be an upgrade before my studies begin. Oh no. New tech! I'm planning a used ThinkPad with Nvidia graphics and AMD processor. I don't feel like adding to the horror that is the environment right now with brand new tech.

Anyway, thank you for reading my little update, I'll try to keep this page updated as I learn more and develop as a web developer. I think it will be interesting for me when I am more experienced to come back and read what I have written.
